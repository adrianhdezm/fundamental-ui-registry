# Component notes

One file per component (and `datetime.md` for `registry/lib/datetime.ts`), written while porting it to React: where
it comes from (fundamental-react, the Angular package, fundamental-styles), how its API maps to theirs, what Base UI
does for it, the deliberate differences from Angular and fundamental-react, and the visual differences from
fundamental-styles that are kept on purpose.

Update a component's file when its API or one of these decisions changes.
