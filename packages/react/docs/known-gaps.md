# Known gaps

What the React package does not port. Remove an entry in the pull request that closes it.

## Not ported

- **Table**: fundamental-react's table, out of scope.
- **What the Angular package does not port from `@fundamental-ngx/core` either**: object-page, truncate,
  global-config, theming and the datetime adapters. The features it lists as blocked (drag and drop lists, the card
  bar chart list, search result lists, popover mobile mode and placement containers, router-driven stories) are
  missing here too; see the Angular package's [known gaps](../../angular/docs/known-gaps.md).
