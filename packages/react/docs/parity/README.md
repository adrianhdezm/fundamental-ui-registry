# Porting tracker: React registry

This folder tracks the port of the components to React: which sources each one comes from, how its stories compare
with them, and how it looks next to fundamental-styles. [`components/`](components/) has one report per component.

## Sources

- **[fundamental-react](https://github.com/SAP/fundamental-react)** (`SAP/fundamental-react` `main` at
  [`490bd2f`](https://github.com/SAP/fundamental-react/tree/490bd2fca46e0fb09e48e488c9d7c030a166c6bf), May 2026):
  React 17, Storybook 6, fundamental-styles 0.26. Its 41 component folders other than Table map to 45 registry
  components (Button also gives segmented-button; Forms gives form, input, checkbox and radio). Its stories are an
  input; its code is not copied (class names, Popper, Moment and prop-types are gone).
- **The Angular package** ([`packages/angular`](../../../angular/)): the API, behaviour, ARIA, keyboard handling and
  Tailwind classes of every component, themselves ported from `@fundamental-ngx/core`. Nothing is imported from it:
  code is rewritten in React with Base UI.
- **[fundamental-styles](https://sap.github.io/fundamental-styles/)**: the visual reference.

## Phases

1. **Phase 1:** the 45 components with a fundamental-react source, in dependency order (icon and button first).
2. **Phase 2:** the other Angular components, which have no fundamental-react source, ported from the Angular package.

That gives 94: Angular's 92 plus counter and search-input, which have no Angular equivalent. Table is out of scope.

## When a component is done

- Stories cover every example of the fundamental-react stories and of the Angular stories (minus n/a ones, such as
  fundamental-react's `cssNamespace` "no styles" stories), with "Open: …" stories for overlays.
- The spec covers the behaviours of the Angular spec and of the fundamental-react tests, in Vitest browser mode.
- `pnpm check` passes: typecheck, styles, registry, tests, and axe on every story in Horizon and Horizon HC Black.
- **Visual:** `pnpm visual <name>` compares chosen elements with the matching fundamental-styles stories in all 16
  combinations of theme (Horizon, Dark, HC Black, HC White), density (cozy, compact) and direction (LTR, RTL), by
  computed style and by pixels with a 3% tolerance. Cozy and compact in Horizon, LTR and RTL, are also reviewed by
  eye in Storybook. Every difference is fixed, or kept with the reason when the Fiori guidelines say fundamental-styles
  is wrong, and logged in the component's report. Combinations fundamental-styles cannot render are checked against
  the SAP tokens and marked so.
- The report in `components/<name>.md` is written and `tracker.json` says `done` with the visual result.
