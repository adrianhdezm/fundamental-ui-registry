fundamental-ui-registry

SAP Fiori Horizon components as copy-paste source, styled with Tailwind CSS v4 on the SAP theme tokens and distributed as shadcn registries. An unofficial port of SAP's Fundamental Library.

  • Angular

    Ported from @fundamental-ngx/core, built on the Angular CDK.

    Storybook · Registry index

    npx shadcn add https://adrianhdezm.github.io/fundamental-ui-registry/angular/r/button.json

  • React

    A modern rewrite of fundamental-react, built on Base UI.

    Storybook · Registry index

    npx shadcn add https://adrianhdezm.github.io/fundamental-ui-registry/react/r/icon.json
